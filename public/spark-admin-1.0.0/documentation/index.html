1. Introduction

Spark Admin is a premium, lightweight, responsive Bootstrap 5 Admin Template designed for SaaS platforms, web applications, dashboards, and enterprise web portals.

Architecture Standards:
  • Zero Inline CSS: All styling logic strictly resides inside structured stylesheets.
  • High Component Reusability: Cards, Stat Badges, Progress Bars, Tables, and Action Buttons are modularly designed for effortless developer reuse.
  • Centralized Fonts: Google Fonts are imported via CSS `@import`, avoiding font link tags in HTML files.
  • Modular Script Files: Custom logic is separated into standalone JS files inside assets/js/.
  • Developer Friendly: HTML markup contains helpful inline commentary explaining component structures.

3. Quick Start & Setup

To run Spark Admin locally, simply open any HTML file in your web browser or serve it via a local web server (e.g. Apache, Nginx, VS Code Live Server):

# Example: Serving via simple HTTP server
npx serve .
# or Python simple server
python3 -m http.server 8000

Navigate to http://localhost:8000/index.html to view the dashboard.

5. JavaScript Architecture & Logic

Spark Admin's interactive logic is encapsulated in modular scripts inside assets/js/:

  1. dashboard.js: Handles mobile sidebar off-canvas backdrop, ApexCharts initializations, and dashboard interactions.
  2. auth.js: Manages password visibility toggles and login form validation.
  3. docs.js: Controls documentation copy snippet interactions and smooth scrolling.
// Example: Mobile Sidebar Backdrop Overlay in dashboard.js
const sidebar = document.querySelector('.sidebar-wrapper');
const toggleBtn = document.querySelector('.sidebar-toggle-btn');
let overlay = document.createElement('div');
overlay.className = 'sidebar-overlay';
document.body.appendChild(overlay);

if (toggleBtn && sidebar) {
    toggleBtn.addEventListener('click', function (e) {
        e.stopPropagation();
        sidebar.classList.toggle('show');
        overlay.classList.toggle('show', sidebar.classList.contains('show'));
    });
}

9. Charts & Plugins Integration

ApexCharts Setup

Include ApexCharts CSS in <head> and JS before closing </body>:

<!-- Local CSS -->
<link rel="stylesheet" href="assets/libs/apexcharts/apexcharts.css">

<!-- Local JS -->
<script src="assets/libs/apexcharts/apexcharts.min.js"></script>

Chart container element:

<div id="revenue-chart"></div>

Flatpickr Datepicker Setup

<!-- HTML Input -->
<input type="text" class="form-control datepicker-input" placeholder="Select date range">

<!-- JS Initialization -->
<script>
    flatpickr('.datepicker-input', {
        dateFormat: 'Y-m-d',
        defaultDate: 'today'
    });
</script>
